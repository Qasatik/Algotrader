# План запуска AlgoTrader SaaS — что делать дальше

Дата: 29.08.2026. Цель: первые 50 платящих подписчиков за 4-6 недель,
$10 000 выручки за 3-4 месяца.

## Этап 0 — технический запуск (30-40 минут, один раз)

1. @BotFather → `/newbot` → токен в `.env` как `SAAS_BOT_TOKEN=...`
   (это бот продаж; торговый бот остаётся на своём токене).
2. @userinfobot → свой числовой ID → `.env` в `SAAS_ADMIN_IDS=...`
   (без него никто не подтвердит оплаты через `/admin_pay`).
3. Свой USDT TRC-20 кошелёк → `.env` в `SAAS_USDT_WALLET=...`
   (пустым оставлять нельзя — крипто-инвойсы не заработают).
4. Запуск бота продаж:
   `systemctl --user enable --now carry-saas`
   Проверка: написать боту `/start`, потом `/pricing`.
5. [ГОТОВО 2026-08-29] Telegram-канал создан: https://t.me/algotr4de,
   бот @Alg0tr4debot — администратор, пост №1 опубликован.
6. Автопост работает через GitHub Actions (провайдер режет api.telegram.org,
   локальный таймер `tg-autopost.timer` не используется):
   - секреты репозитория: `TG_BOT_TOKEN` (токен бота) и `TG_CHAT_ID`
     (`@username` канала или числовой `-100...`);
   - воркфлоу `.github/workflows/autopost.yml` сам постит по одному посту
     раз в 2 дня в 12:00 МСК (дни 1-19), ручной запуск — вкладка Actions;
   - проверка токена и поиск ID чатов: Actions → Telegram autopost →
     Run workflow → debug.
7. Залить на хостинг лендинга обновлённые `index.html` и новый `offer.html`.
8. Ссылки на бота обновлены на реальный @username: @Alg0tr4debot
   (посты, лендинг). Проверить его же в шапке канала при создании.

## Этап 1 — неделя 1: первые пользователи (цель: 20 триалов)

- Опубликовать пост-мортем (пост #3 из пакета) в 3-5 крипто-чатах,
  где вы состоите: честные разборы собирают больше доверия, чем реклама.
- Отвечать на каждый комментарий в канале в первые 2 недели — алгоритмы
  Telegram поднимают каналы с активностью.
- Лично позвать 10-20 знакомых, кто уже торгует: триал бесплатный,
  ключи без права вывода — порог входа минимальный.
- Метрики: регистрации `/start`, конверсия в `/connect`, активация триала.

## Этап 2 — недели 2-3: конверсия (цель: 10-15 платящих)

- Смотреть воронку: где отваливаются (нет ключа? страшно? непонятно?).
  Самое частое: «как создать ключ без вывода» — записать скриншот-гайд
  и закрепить в канале.
- Собрать 3-5 отзывов триальщиков (с разрешения — скринами в канал).
- Запустить рефералку: пост #8 + личная рассылка активным триальщикам.
- Первые оплаты подтверждаются вручную `/admin_pay` — проверять
  поступления USDT хотя бы раз в день.

## Этап 3 — недели 3-6: масштабирование (цель: 50 платящих)

- Платное размещение: посевы в 2-3 средних крипто-каналах (10-30k
  подписчиков). Бюджет теста 3-5k ₽. Критерий успеха посева:
  стоимость платящего подписчика < 500 ₽ (окупается за 2 месяца).
- GitHub-трафик: README публичного репо ведёт на лендинг и бота —
  проверить, что ссылки живые.
- Avito: объявление «Настройка торгового бота фандинга под ключ» —
  разовая услуга 100-300 $ конвертирует клиентов в подписку.
- Контент: продолжать автопост (пакет рассчитан на 19 дней), потом
  писать по 2-3 поста в неделю руками: живые скрины дашборда,
  разборы ставок фандинга, ответы на вопросы.

## Этап 4 — месяц 2+: удержание и рост

- Отчёт удержания: кто отменился и почему (бот уже умеет retention-алерты).
- Апсейл Basic → Pro при росте депозитов пользователей.
- Партнёрская программа с администраторами каналов (фикс за приведённого
  платящего вместо посевов).
- Каждые 2 недели — публичный отчёт канала: сколько пользователей,
  сколько сделок открыл бот, честная статистика. Прозрачность = доверие =
  конверсия.

## Ежедневная рутина (15 минут)

1. Проверить журнал бота продаж: `journalctl --user -u carry-saas -n 50`
2. Подтвердить поступившие оплаты (`/admin_pay`).
3. Проверить, что торговый бот жив: `systemctl --user status carry-bot`
   и последняя запись в `logs/carry.log`.

## Красные линии (не нарушать)

- Не обещать доходность и проценты — ни в постах, ни в переписке.
- Не продавать людям с депозитом <$150.
- Не использовать чужие скрины прибыли.
- Каждое упоминание результатов сопровождать «доходность не гарантируется».
